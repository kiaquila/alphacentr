# Alpha Lumen — реализация

Статический сайт: сборка на Node без фреймворка, без сетевых зависимостей и
почти без клиентского JavaScript.

## Команды

```bash
npm --prefix alphacentr/site run build   # собрать dist/
npm --prefix alphacentr/site test        # проверки полноты и ссылок
npm --prefix alphacentr/site run check   # сборка + тесты
npm --prefix alphacentr/site run dev     # сборка и просмотр на localhost:4321
```

Зависимостей нет — `npm install` не требуется. Нужен Node 22.18 или новее.

## Структура

```text
site/
├── scripts/
│   ├── build.mjs          # рендер маршрутов в dist/, сборка CSS, копирование ассетов
│   └── serve.mjs          # статический сервер для локального просмотра
├── src/
│   ├── routes.mjs         # таблица маршрутов — единственный источник истины
│   ├── lib/html.mjs       # экранирование, шаблонные литералы, блоки контента
│   ├── data/              # таксономия, навигация, реквизиты, вводные тексты
│   ├── content/           # перенесённый контент в JSON
│   ├── templates/         # оболочка, шапка, подвал, переиспользуемые блоки
│   ├── pages/             # генераторы маршрутов по разделам
│   ├── styles/            # токены и слои CSS
│   └── client/nav.js      # единственный клиентский скрипт
├── assets/                # шрифты и favicon
└── tests/                 # проверки полноты контента
```

Файл кода не превышает 600 строк. Контент вынесен в JSON под `src/content/`,
поэтому объём материала не влияет на читаемость кода.

## Как рендерится страница

`buildRoutes()` собирает список `{ path, html }` из генераторов в `src/pages/`.
Каждый генератор берёт данные из `src/data/`, собирает тело шаблонными
литералами и оборачивает его в `layout()`.

Всё, что подставляется через `html`, экранируется. Чтобы вставить готовую
разметку, её нужно явно обернуть в `raw()`. Перенесённые тексты описываются
блоками `{ type: "p" | "h2" | "h3" | "ul" | "ol" | "quote" | "note" }`;
неизвестный тип роняет сборку, а не теряет текст молча.

Внутри текстов поддерживаются два инлайновых формата: `[текст](/путь/)` для
ссылок и `*текст*` для акцента. Все ссылки нормализованы к каноническим
адресам и проверяются тестом.

## Дизайн-система

CSS собирается из пяти слоёв в фиксированном порядке: `tokens` → `base` →
`layout` → `components` → `pages`. Токены — в `src/styles/tokens.css`.

- Поверхности: греж-подложка страницы `--shell`, бумажная панель `--paper`,
  светлые секции `--cream`, тёплый песок `--sand`.
- Текст: почти-чёрный `--ink`, приглушённые `--ink-muted` / `--ink-soft`.
- Зелёные: `--forest` для заголовков, `--forest-deep` для подвала и полосы
  подписки, `--sage` для кнопок и меток, `--sage-deep` для подписей на светлом.
- Типографика: один гротеск **Inter** (самостоятельный хостинг, вариативный
  woff2, отдельные подмножества для кириллицы и латиницы) — сеть не
  используется вообще. Крупные кегли идут с отрицательным трекингом
  (`--track-display`, `--track-heading`), надзаголовки — с разрядкой.
- Шкала кеглей и отступов задана через `clamp()`, поэтому макет тянется без
  скачков между брейкпоинтами.

Брейкпоинты: 1180 px (сжатие меню), 1000 px (двухколоночные блоки в одну
колонку), 960 px (мобильное меню), 640 px и 620 px (мелкая доводка).

## Айдентика и фотографии

`assets/logo-mark.svg` — гипнотическая спираль, перерисованная с оригинального
логотипа; тот же файл используется как `favicon.svg`. Вордмарк «МЕДИТАЦИИ /
Елены Вальяк» набирается текстом, поэтому масштабируется и читается поисковиками.

`assets/media/` — перенесённые с оригинала обложки сеансов, иллюстрации статей
и портрет автора. Соответствия хранит `src/content/media.json`, доступ к ним —
через `src/data/media.mjs`. Тест проверяет, что каждый упомянутый в разметке
файл существует.

## Клиентский JavaScript

`src/client/nav.js` — около 70 строк (2 КБ): мобильное меню, закрытие соседних
меню, клик мимо и Escape. Скрипт подключён с `defer`.

Без него сайт остаётся полностью рабочим: меню каталога, помощи и автора — это
нативные `<details>`, навигация видна по умолчанию, аккордеон «Вопрос-ответ»
тоже построен на `<details>`. Скрипт добавляет только то, чего браузер не даёт
сам.

| Ресурс | Размер | В gzip |
| --- | --- | --- |
| Главная (HTML) | 42 КБ | 9 КБ |
| `styles.css` | 33 КБ | 7 КБ |
| `nav.js` | 2 КБ | — |

Первая загрузка для русскоязычного посетителя — около 39 КБ. Латинские и
курсивные подмножества шрифта подгружаются только при необходимости, сторонние
запросы отсутствуют полностью.

## Тесты

`tests/routes.test.mjs` проверяет:

- уникальность и нормализованность всех маршрутов;
- что каталог, статьи и страницы перенесены в полном объёме и без пустых тел;
- что каждый сеанс достижим хотя бы из одной категории;
- что каждый пункт навигации ведёт на существующую страницу;
- что все внутренние ссылки в готовом HTML разрешаются.

## Публикация на stage

Сайт статический, поэтому на Cloudflare он раздаётся Workers Static Assets из
`dist/`. `worker/index.ts` нужен только для заголовков безопасности (CSP,
HSTS, `X-Frame-Options` и прочее) — их пайплайн ассетов сам не проставляет.

| Настройка | Значение |
| --- | --- |
| Имя Worker | `alphacentr` |
| Стабильный URL | `https://alphacentr.ks-design.workers.dev` |
| Корневой каталог | `alphacentr/site` |
| Команда сборки | `npm run build` |
| Деплой стабильного стенда | `npm run stage:deploy` |
| Превью для ветки | `npm run stage:preview` |
| Отслеживаемый путь | `alphacentr/*` |

Репозиторий `kiaquila/web-design` подключён к Worker через Workers Builds.
Учётные данные и токены живут только на стороне Cloudflare и в репозитории не
хранятся.

## Вывод сборки

`dist/` содержит 825 HTML-страниц (416 уникальных материалов плюс сохранённые
альтернативные адреса оригинала), один CSS-файл, один JS-файл, четыре файла
шрифтов, favicon, `sitemap.xml` и `robots.txt`. Каталог сборки не версионируется.
