# Alpha-Centr — редизайн «Альфа Люмен»

Редизайн действующего сайта гипнолога Елены Вальяк
([alphacentr.ru](https://alphacentr.ru/)) — авторского каталога сеансов
гипноза, медитаций и аффирмаций в формате mp3.

Проект содержит полностью переработанный, статически собираемый сайт, в который
перенесён весь контент оригинала: каталог, статьи, страницы автора, справочные и
юридические материалы, отзывы, новости, формы и переходы в соцсети.

## Концепция

**«Альфа Люмен» / Alpha Lumen** — светлая тема в тёплой греж-палитре: бумажная
подложка, глубокая зелень для заголовков, шалфейные акценты.

- *Альфа* — альфа-ритм мозга, состояние, в котором работает гипноз, и корень
  исторического названия проекта.
- *Люмен* — свет: концепция намеренно выполнена в светлой теме (тёмные буквы на
  светлом фоне).

Направление: один гротеск Inter, крупные плотно набранные заголовки с
отрицательным трекингом, широкие поля, много воздуха, крупная фотография. Тон —
спокойный, профессиональный, премиальный. Избегаем эзотерической стилистики,
кричащих распродажных элементов и медицинских обещаний.

### Айдентика

Знак и вордмарк перерисованы с действующего логотипа alphacentr.ru:

- **Знак** — гипнотическая спираль, воссозданная в SVG по геометрии оригинала
  (архимедова спираль с сужающимся каналом, ~2 витка). Градиент переведён из
  зелёно-сине-фиолетового оригинала в зелёно-бирюзовый, чтобы жить в новой
  палитре. Один файл работает и логотипом, и фавиконом.
- **Вордмарк** — «МЕДИТАЦИИ / Елены Вальяк», как на оригинальном логотипе:
  верхняя строка жирным гротеском, нижняя — разрядкой капителью.

### Фотографии

Перенесены с оригинала: 256 обложек сеансов, 106 иллюстраций статей и портрет
автора. Права принадлежат автору проекта и подтверждены заказчиком. Исходные
изображения разного качества и стиля — часть в высоком разрешении, часть
170–340 px, — поэтому полноэкранная фотографическая шапка не строилась: первый
экран собран типографикой и портретом автора в рамке.

## Что изменено осознанно

- **Навигация.** В оригинале пять верхних меню с продублированными подсписками.
  Здесь шесть предсказуемых пунктов: три меню (Сеансы, Автор, Помощь) и три
  прямые ссылки (Статьи, Отзывы, Контакты). Все прежние адреса сохранены.
- **Первый экран.** Слайдер из трёх слоганов заменён одним типографским
  утверждением — быстрее грузится и лучше читается.
- **Карточка сеанса.** Цена, длительность, размер файла и условия доставки
  собраны в липкий блок; отзывы к программе вынесены отдельной секцией.
- **Каталог.** Добавлены счётчики программ и короткие описания категорий, чтобы
  выбор темы не требовал перехода на страницу.

Полный список расхождений с оригиналом, включая осознанные исключения, — в
[`CONTENT-AUDIT.md`](./CONTENT-AUDIT.md).

## Открытые вопросы к заказчику

1. **Формы.** Оригинал отправляет подписку, вопросы и отзывы в бэкенд Bitrix.
   Статическая версия не имеет бэкенда, поэтому формы адресованы на почту
   автора. Перед запуском нужно подключить реальный обработчик.
2. **Корзина и оплата.** Каталог перенесён как витрина: кнопки ведут на
   инструкцию по оформлению заказа. Приём платежей остаётся на стороне
   действующего магазина.
3. **Телефон.** Номер из разметки оригинала не публикуется как контакт: в шапке
   и подвале он закомментирован, а в мобильном блоке скрыт стилем. Поэтому в
   интерфейсе редизайна остаются почта и форма. Другой номер сохранён дословно в
   публичной оферте; не менять юридический текст и не добавлять номер в интерфейс
   до письменного подтверждения автора.
4. **Тексты книг.** Две страницы раздела «Книги на тему психологии» содержали
   полные тексты книг, защищённых авторским правом. Перенесены только выходные
   данные и вступление — см. `CONTENT-AUDIT.md`.

## Codex review automation

Run the gate regression suite with `node --test tests/*.test.mjs` (also run by
Project CI). Review evidence remains bound to the requested PR head and the
trusted `chatgpt-codex-connector[bot]` identity. Legacy no-findings comments and
native `codex-review-receipt:v1` comments require an explicit clean verdict and
the reviewed commit. Formal native reviews remain supported. Unresolved Codex
review threads block the gate, including findings from an earlier head.

Created and edited receipt/summary comments wake the trusted default-branch
gate. The mutable `codex-pull-request-review-summary` / `codex-review-state:v1`
summary is only a wakeup signal, never successful review evidence. Its original
creation time therefore does not prevent an edit from waking the gate. Requeue
waits for active runs, serializes native events, and skips evidence already
evaluated by a later run; new edits trigger another evaluation. Both requeue
and gate validation recheck the live PR head to guard against concurrent pushes.

When installing a routing fix, the PR still executes the gate from `main`.
After a trusted current-head review request and a real native receipt/review,
rerun the existing PR workflow through GitHub Actions if the old event filter
misses the notification. This evaluates real evidence with the trusted policy;
it does not execute proposed gate code with elevated permissions. Once merged,
the new event routing takes effect on the default branch.
