# AGENTS.md — Alpha-Centr

Действующий сайт гипнолога Елены Вальяк. Этот каталог содержит редизайн под
концепцией **«Альфа Люмен»** и перенесённый контент оригинала.

## Идентичность продукта

- Утверждённая концепция: **Альфа Люмен / Alpha Lumen**.
- Направление: тёплая греж-палитра, глубокая зелень для заголовков, шалфейные
  акценты, один гротеск Inter с плотным трекингом на крупных кеглях, широкие
  поля, крупная фотография.
- Знак — гипнотическая спираль, перерисованная с оригинального логотипа
  (`assets/logo-mark.svg`, он же фавикон). Вордмарк — «МЕДИТАЦИИ / Елены
  Вальяк». Не заменять знак и не менять структуру вордмарка без запроса.
- Тон: спокойный, профессиональный, премиальный. Избегать эзотерической
  стилистики, распродажной верстки, обещаний излечения и медицинских гарантий.
- Тема намеренно только светлая. Не добавлять тёмную тему без запроса.

## Источники истины

- `README.md` — контекст, концепция, осознанные изменения, открытые вопросы.
- `CONTENT-AUDIT.md` — провенанс каждого блока контента, исключения, расхождения.
- `site/src/content/**` — канонический перенесённый контент в JSON.
- `site/src/data/*.mjs` — таксономия, навигация, реквизиты и вводные тексты.
- `site/src/content/media.json` — карта «сеанс/статья → изображение».
- `site/src/styles/tokens.css` — токены дизайн-системы.
- `web-design.config.json` — обязательные проверки и бюджеты веса страниц.
- `docs/migration/` — провенанс переноса и план перехода Cloudflare.

Не менять факты, цены, длительность, реквизиты, контакты, юридические тексты и
формулировки автора без подтверждённого источника или явного согласия заказчика.
Любое изменение фактического контента фиксировать в `CONTENT-AUDIT.md`.

## Правила реализации

- Сайт собирается статически на Node без фреймворка и без сетевых зависимостей.
  Не вводить CDN, трекеры, встраивания и внешние шрифты.
- Файл кода — не более 600 строк. Контент живёт в JSON под `site/src/content/`
  и под это ограничение не подпадает.
- Публичные URL сохранены как на alphacentr.ru. Не переименовывать маршруты.
- Клиентский JavaScript — только `site/src/client/nav.js`. Страница обязана
  оставаться пригодной к использованию без него.
- Каждый новый маршрут добавлять через `site/src/routes.mjs` и покрывать
  проверкой полноты в `site/tests/routes.test.mjs`.
- Внутренние ссылки в перенесённых текстах записываются как `[текст](/путь/)`
  и обязаны разрешаться в существующий маршрут — это проверяется тестом.
- Не воспроизводить материалы третьих лиц: тексты книг, статьи изданий,
  телесюжеты. Допустимы название, автор и ссылка.

## Проверки

Из корня репозитория — ровно то, что запускает CI:

```bash
npm ci --ignore-scripts                 # один раз, зависимости harness (yaml)
npm ci --ignore-scripts --prefix site   # один раз, зависимости сайта
npm run preflight                       # guard, тесты harness, сборка и тесты
                                        # сайта, бюджет веса страниц
```

`preflight` — это ровно то, что запускает `project-ci`. Отдельные шаги:
`npm run check:repository`, `npm run test:harness`, `npm run check:project`
(`npm --prefix site run check`), `npm run check:budget`.

Бюджет веса измеряется по representative-страницам, а не по всему `dist/`:
сайт генерирует 828 страниц, поэтому суммарный вес всех HTML и изображений не
отражает вес одной пользовательской страницы. Значения и обоснование —
в `web-design.config.json` и `docs/testing.md`. Менять предел только по
новому измерению и с объяснением в PR.

Для визуальных изменений дополнительно проверять узкий (375 px) и широкий
(1280 px и более) макеты, состояния фокуса с клавиатуры, работу мобильного меню
и раскрывающихся списков, а также самые длинные заголовки категорий и сеансов.
